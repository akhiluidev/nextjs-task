# NextShop - Next.js E-Commerce Application

## Project Overview

NextShop is a mini e-commerce product showcase website developed using **Next.js + TypeScript**.  
The application demonstrates product listing, product details, cart functionality, login handling, guest user access, responsive UI, and SEO optimization.

---

## Implemented Features

- Login Page
- Register Page
- Product Listing Page
- Product Search Functionality
- Product Filter by Category
- Add to Cart Functionality
- Cart Page
- Dynamic Cart Count
- Cart Total Price Calculation
- About Page
- Contact Us Page
- Responsive Navigation Bar
- Guest User Handling
- Responsive UI Design

---

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React Hooks
- Local Storage

## Installation

### Clone the Repository

```bash
git clone <repository-url>
```

### Move to Project Folder

```bash
cd my-app
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Open in Browser

```bash
http://localhost:3000
```

## Performance Optimizations

- Implemented `useMemo` for efficient product filtering and reduced unnecessary re-renders
- Used reusable components to maintain clean and scalable code structure
- Responsive UI optimized for mobile, tablet, and desktop devices
- Lightweight application structure for better performance and smooth user experience
- Used local static product data for faster rendering
