# NextShop - Next.js E-Commerce Application

## Project Overview

NextShop is a mini e-commerce product showcase website developed using **Next.js + TypeScript**.  
The application demonstrates product listing, product details, cart functionality, login handling, guest user access, responsive UI, and SEO optimization.

---

## Features

- Home Page with Hero Section
- Product Listing Page
- Search & Filter Functionality
- Add to Cart Functionality
- Cart Page
- Login & Guest User Handling
- About Page
- Contact Page
- Responsive Design
- Reusable Components
- SEO Optimization

---

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Local Storage

## Installation

### Clone the Repository

```bash
git clone <repository-url>
```

### Move to Project Folder

```bash
cd my-app
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Open in Browser

```bash
http://localhost:3000
```
